Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses
✍️ Zhaochen Yu, Yingcheng Wu, Zhenfei Yin, Kaiyuan Chen, Zhe Zhao 等🏷️ cs.AI, cs.CL📎 2608.24876

递归自改进（RSI）在长程任务中仍具挑战，增长的历史会遮蔽任务状态并误导技能调用。提出 Recuris，一种递归经验-工作记忆架构：工作记忆追踪任务进度并从经验记忆中引导技能选择，将执行转化为结构化证据以定位失败到特定记忆组件。固定 Meta-Agent 将这些证据转化为局部化修复，在长程编码与工具使用任务上持续提升。

2 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.2🌟
BrowserForge: Scaling Web Episode via Parallel Browser Sandboxes
✍️ Fei Tang, Huawen Shen, Zhiqiong Lu, Zhengxi Lu, Pengyuan Lyu 等🏷️ cs.CL📎 2608.24848

像素级 Web Agent 训练依赖大量高质量交互轨迹，但公开数据集仅覆盖数千条轨迹和极窄网站集合。BrowserForge 通过并行浏览器沙箱框架大规模合成 Web 交互数据，突破预定义站点列表限制，使训练数据中网站多样性大幅增长，显著提升像素级 Web Agent 的泛化能力。

3 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.2🌟
StarHarness: Evolving Harnesses with Stratified Search for Enterprise Environments
✍️ Esakkivel Esakkiraja, Denis Akhiyarov, Vikas Yadav, Sai Rajeswar, Patrice Bechard 等🏷️ cs.AI, cs.SE📎 2608.24804

提出 StarHarness 框架，在保持模型权重固定的同时进化环境特定的 Agent harness（含提示、工具接口、技能、MCP 提供者、子 Agent 结构与循环配置）。通过按基线失败行为分层任务、分离提议者可见/隐藏搜索任务、预留留出任务评估泛化，在 ITBench SRE、EnterpriseOps-Gym ITSM 与 AutomationBench Finance 上显著提升。

4 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.2🌟
Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning
✍️ Sixiang Chen, Jiaming Liu, Jixian Wu, Yichen Guo, Tinghao Wang 等🏷️ cs.RO, cs.CV📎 2608.24885

动作条件世界模型被用作策略评估与改进的学习模拟器，但其有效性依赖于未经验证的假设：生成未来忠实反映任意有效动作。提出 WorldEcho，用视觉完整性与 SE(3) 轨迹对齐探测更广泛动作分布上的动作跟随。诊断显示当前世界模型在专家演示动作上表现合理，但在离专家动作上显著退化，并提出对齐方法改善。

5 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.1🌟
SPO++: Stream-Aligned Policy Optimization for Asynchronous Agentic RL
✍️ Kai Ruan, Jinghao Lin, Qianshan Wei, Ziqi Zhou, Zihe Huang🏷️ cs.AI📎 2608.24870

Group-relative RL 需等待同 prompt 的兄弟 rollout，对长且可变工具使用轨迹代价高昂。SPO 用持久 prompt 级价值估计消除该依赖，但其方案在每个轨迹上白化一个 advantage 再优化 token-mean actor loss。本文证明轨迹居中通常不会使 token 加权量居中，通过 action-token 度量下标准化终端结果 advantage 修复不匹配，并组织 prompt 证据提升异步 Agentic RL 效率。

6 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.1🌟
Latent Action as Intention Enables Efficient Future Imagination for World Action Models
✍️ Xiang Li, Yupeng Zheng, Songen Gu, Huailiang Ma, Feng Yu 等🏷️ cs.RO📎 2608.24882

World Action Models 通过建模观测演化改善机器人控制，但测试时生成未来观测产生大量延迟。Fast-WAM 移除此过程以提升效率，但匹配实现显示其泛化性低于未来感知替代方案。提出 LAWA，用紧凑潜在动作作为未来意图的操作表征，实现高效测试时未来想象，在稀缺机器人演示与 OOD 场景下弥合效率-泛化鸿沟。

7 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.1🌟
Effective Learning Rate Governs Loss Dynamics in Language Model Pretraining
✍️ Zihan Liu, Ruiheng Zheng, Shaobo Zhang, Changxin Tian, Kunlong Chen 等🏷️ cs.LG📎 2608.24814

揭示语言模型预训练中的 ELR collapse 现象：学习率与参数范数主要通过其比值（有效学习率 ELR）调控损失动态。当 ELR 匹配时，尽管 LR 和参数范数差异显著，损失轨迹在整个训练过程中坍缩一致。跨优化器、架构、数据集与模型规模，平均坍缩误差通常在 10⁻³ 量级，低于代表性配置中的种子间变异。

8 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.0🌟
What FID Hides: Detecting, Ranking, and Diagnosing Deviations in Generative Evaluation
✍️ Hao Chen🏷️ stat.ML, cs.LG📎 2608.24881

生成模型常用 FID/KID 排名，但 FID 的一二阶矩摘要可能遗漏分布差异，标量差距本身不是针对采样变化的校准检验。在 ImageNet 上，仅匹配参考 Inception 均值/协方差的视觉不可辨图像获得 FID 24.7，而留出真实图像为 58.6。提出检测、排序与诊断生成评估偏差的系统框架，揭示 FID/KID 作为标量差异在交换样本时不变的固有局限。

9 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.0🌟
LeFlow: Generative Latent Flow Planning for World Models
✍️ Hsiang-Wei Huang, Jianxu Shangguan, Junbin Lu, Jenq-Neng Hwang🏷️ cs.CV📎 2608.24855

潜在世界模型是强编码器，但现有方法仍依赖在线轨迹优化进行动作规划：每个状态-目标对都从头运行迭代优化器。提出 LeFlow，问规划本身能否在潜在世界模型学习后被摊销。通过生成式潜在流匹配学习规划分布，避免每步重规划的全迭代优化代价，且不跨查询复用规划经验。

11 ⭐⭐⭐⭐⭐⭐⭐ 评分 7.0🌟
Reading Is Not Using: Retrieval, Judgment, and the Design of AI Financial Research Workflows
✍️ Miao Liu, Zhizhe Liu🏷️ cs.CL, cs.AI📎 2608.24842

LLM 越来越多部署为 AI 分析师处理金融披露，但系统通常以检索能力而非检索信息是否影响判断来评估。识别长上下文金融分析中的检索-整合鸿沟：固定焦点公司信息、仅变化无关上下文从 2K 到 128K token，发现风险披露对投资判断的影响降至实验噪声水平，即使直接检索仍然准确。提出重新设计 AI 金融研究工作流。

Structurally-bounded Agentic Graph Exploration for Evidence-Grounded Scholarly DeepSearch
✍️ Rima Hazra, Sayan Layek, Somnath Banerjee, Soumen Chakrabarti, Animesh Mukherjee🏷️ cs.CL, cs.IR📎 2608.24809

提出 Crase，一种有界且可检查的学术深度搜索替代方案。Crase 仅查询搜索引擎一次获取种子论文，沿 1.5-hop 引用邻域扩展，剪除缺乏蕴含支持的引用边，用 recency-aware 随机游走排序剩余论文。候选集、保留原因与停止条件在推理前显式固定。在 LitSearch 与 500K 论文 arXiv 语料上超越深度研究 Agent。
