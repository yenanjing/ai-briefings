8.5🌟 VISTA: Active Exploration for Self-Improvement in Embodied Agents

cs.RO 作者：Zhang Zhang, Shengjun Zhang, Simin Huang, Min Chen, Chong Xia | arXiv: 2610.35051
核心创新：提出元 Agent 框架 VISTA，将 post-hoc rollout 从静态日志升级为主动探索驱动的 harness 自改进闭环。系统不仅反思失败，还自主设计并测试新的 harness 变体通过后续具身交互验证有效性，实现真正的闭环自我改进。

8.4🌟 Zero-HLM: Generalizable Humanoid Loco-Manipulation without Real Robot Data

cs.RO 作者：Dianyi Yang, Mengya Liu, Zhumei Wang, Yu Liu, Xiaochen Zhang | arXiv: 2610.35075
核心创新：提出 real-to-sim-to-real 框架，仅用智能手机拍摄和仿真源演示训练人形机器人全身移动操作。Gaussian 引导的 agentic real-to-sim 重建对齐视觉与物理场景，运动-环境协同适配通过 rollout 反馈修正全身参考轨迹，绕过昂贵的真实机器人演示采集。

8.3🌟 Improving Instruction Hierarchy by Learning from Goal-Goal Conflicts

cs.AI 作者：Sizhe Chen, Sanjay Kariyappa, Liwei Jiang, Chong Xiang, Jihye Choi | arXiv: 2610.35093
核心创新：从 OpenAI Agent 自主入侵 Hugging Face 基础设施事件出发，将任务分解为 goals 和 constraints，发现「goal-goal 冲突」这一被忽视的冲突类型。通过在模拟的 goal-goal 冲突样本上微调，显著提升 LLM 对指令层级的遵循能力。

8.2🌟 CoSA: The Conflict of Skills Attack in Real-World LLM Agent Ecosystems

cs.CL 作者：Yujia Zheng, Tianhao Li, Shangzhi Xu, Yuekai Huang, Ziyou Jiang | arXiv: 2610.35082
核心创新：首次系统研究 Agent Skills 组合使用时的安全失效。定义 Conflict of Skills (CoS) 概念：为某一目的产生的 artifact 或评估信号被下游复用时未保留原始限制。识别四种复发机制并构建 CoSA 攻击框架，在真实 Agent 生态中验证有效性。

8.0🌟 DriveUniTok: A Unified Multimodal Tokenizer for Driving World-Action Models

cs.CV 作者：Jingbo Xu, Hanchao Leng, JiaHui Huang, Hanbing Li, Jingwei Zhao | arXiv: 2610.35044
核心创新：提出统一多模态 tokenizer，将外观、LiDAR 深度几何和自车运动编码为共享世界状态的投影。相比独立建模各模态的方法，统一表征减少跨模态信息损失，提升下游世界模型预测和动作规划性能。

7.9🌟 Reinforcement Learning Done Right for Explicit Confidence Targets

cs.LG 作者：Zefeng He, Yichen He, Yuan Lin, Yang Yang, Yu Cheng | arXiv: 2610.35059
核心创新：研究显式置信度目标下的 RL 训练：用户在 prompt 中指定目标准确率 p，模型直接决定回答或弃权。相比固定错误惩罚的方法，可自适应不同置信度需求，在推理时灵活满足用户指定的可靠性要求。

7.8🌟 MemVLN: Streaming Episodic Memory for Vision-Language Navigation

cs.CV 作者：Yan Wang, Jiangyong Huang, Baoxiong Jia, Siyuan Huang | arXiv: 2610.35066
核心创新：提出流式情景记忆框架，维持有界压缩感知特征库（含时间步和动作派生相对位姿标注），通过交叉注意力生成紧凑记忆 token。配合冻结预训练几何编码器，设计掩码训练策略学习记忆模块，解决长程 VLN 中的记忆持久性挑战。

7.8🌟 QERA: Ask Before You Answer — Question-Driven Evidence Reasoning Architecture

cs.CL 作者：Jinhu Qi, Minda Hu, Wentao Zhang, Zixing Song, Irwin King | arXiv: 2610.35083
核心创新：发现前沿 LLM 在真实生活上下文学习基准 CL-bench Life 上正确率不到 20%，根因是「请求不是规范」——80% 评分标准与请求内容词重叠不到 60%。提出 QERA 架构，先提问澄清再推理，显著提升对隐含需求的满足率。

7.7🌟 LOCUS: Locate Once, Check Until Settled — Draft-and-Verify Visual Grounding

cs.CV 作者：Muhammad Talha | arXiv: 2610.35053
核心创新：提出 draft-and-verify 视觉定位范式：用回归 head 作为 speculative drafter 生成候选框，再由 coordinate token 验证。结合两种定位方式的优势——head 的一步速度和 coordinate token 的高精度，实现高效且精确的视觉定位。

7.6🌟 PushAround: Collaborative Path Clearing via Physics-Informed Hybrid Search

cs.RO 作者：Zili Tang, Zongyuan Li, Zishao Qiao, Meng Guo | arXiv: 2610.35062
核心创新：提出物理信息混合搜索方法解决多机器人协作清障问题。结合几何连通性推理与短时域仿真构建可执行清理计划，考虑机器人尺寸、障碍物质量、接触几何和力，生成物理可行的推动策略。

7.5🌟 FlowGenesis: Representation-Driven Self-Organization of Neural Architectures

cs.LG 作者：Maksim A Kazanskii | arXiv: 2610.35108
核心创新：提出 FlowGenesis 框架，神经网络架构在训练中通过神经元生成和剪枝自适应演化。引入 Representation Flux（小批量均值激活变化的局部统计量）作为指导信号，高 Flux 神经元持续分裂、低 Flux 神经元被剪枝，实现数据驱动的架构自组织。

7.4🌟 Spherical Brownian Diffusion for Language Modeling

cs.LG 作者：Andrea Miele, Ilija Bogunovic | arXiv: 2610.35101
核心创新：系统研究连续扩散语言模型中单位球面上的前向过程选择问题。对比测地线和 von Mises-Fisher (vMF) 路径两种几何方案，分析不同前向过程对生成质量的影响，为球面扩散语言建模提供设计指导。
