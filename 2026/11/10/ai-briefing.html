📝 今日主题

Agent 认知与探索理论——Sampling Is Not Curiosity 论证当前 LLM agent 的探索是「随机采样」而非「好奇调查」并提出形式化框架；Value-Policy Dissociation 揭示 agent 能从隐藏状态线性解码候选动作价值却无法可靠转化为策略选择，Natural Value Transport 干预可改善任务结果。

Agentic RAG 与 RL 基础设施——PatternBloom 将 agentic RAG 的检索单位从「内容」升级为「推理逻辑」，7B 模型在 27 基线上 +15.0 Avg-OOD EM；BunshinRL 通过活体工作区 fork 削减 agentic RL 峰值内存 43%、延迟 23%。

本地推理与系统效率——Hibana 面向 DGX Spark 统一内存设备协同优化模型表示/内存管理/解码策略，125B 模型 agentic 吞吐 3.4×；GEAR 将 NN 验证的线性边界传播迁移至全局 NLP，超越 Gurobi/BARON/SCIP。

模型编辑与知识可恢复性——Memento 证明编辑后知识可仅通过 prompt 空间干预恢复 80.07%，揭示编辑抑制而非消除知识的可恢复性。

具身智能触觉替代视觉——手指触觉传感器在接触密集操作中提升 31.7-60.0pp，超越腕部相机策略。

📄 精选论文（Top 12）

9.0🌟 PatternBloom: Empowering Agentic RAG with Externalized RL-Distilled Graph Patterns

  • 作者: Yi Ge; Heng Huang
  • arXiv: 2611.10477
  • 代码: github.com/EllenYiGe/PatternBloom
  • 分类: cs.AI
  • 核心创新: 将 agentic RAG 的检索单位从「内容（读什么）」升级为「逻辑（怎么推理）」。第一阶段 RL 用冻结 oracle 的信息增益（IDR）给证据图打分，高奖励轨迹蒸馏为类型抽象的推理骨架库（GPM）；第二阶段 RL 用 Pattern-Augmented Reward 耦合策略与记忆。7B 模型在 27 个基线上 +15.0 Avg-OOD EM，增益随推理深度复合增长。

8.8🌟 Sampling Is Not Curiosity: Why LLM Agents Should Investigate

  • 作者: Alfonso Amayuelas; Piotr Piękos; Xin Eric Wang; William Yang Wang
  • arXiv: 2611.10501
  • 分类: cs.AI
  • 核心创新: 立场论文，论证当前 LLM agent 的探索是「随机采样」而非「好奇调查」。从 RL 好奇心文献出发，提出 LLM agent 好奇心的形式化框架：需要预测性环境模型、在线改进、通过预测改进驱动动作选择、超越上下文窗口持续存在，并在开放式设定下自主发起调查目标。

8.8🌟 Hibana: Fast Agentic Inference on Unified-Memory Devices

  • 作者: Yahya Emara; Chi-Chih Chang; Anthony Fei; Ahmed F. AbouElhamayed
  • arXiv: 2611.10469
  • 代码: github.com/sharar-project/hibana
  • 分类: cs.CL, cs.AI
  • 核心创新: 面向统一内存设备（DGX Spark）的推理引擎，协同优化模型表示（model surgery 缩减内存与数据搬运）、内存管理（跨轮次保留 agent 状态实现即时恢复）、解码策略（自适应投机）。单卡 DGX Spark 服务 125B 模型，agentic 任务吞吐 3.4×、解码吞吐 3.9× 超越 vLLM/llama.cpp。

8.5🌟 GEAR: A GPU-Accelerated Global Solver for Bounded Continuous Nonlinear Programs

  • 作者: Duo Zhou; Hesun Chen; Xiangru Zhong; Grani A. Hanasusanto
  • arXiv: 2611.10487
  • 分类: math.OC, cs.LG
  • 核心创新: 受神经网络验证中线性边界传播框架启发的 GPU 加速全局 NLP 求解器。将线性边界视为非线性约束的松弛，用于下界、不可行检测与原始解搜索；提出双线性/商/三角函数的更紧线性松弛与投影增广拉格朗日法。在 GAMS/MINLPLib 基准 180s 限制内解决 421/505 题，超越 Gurobi/BARON/SCIP 等 6 个求解器，16 题为唯一求解。

8.5🌟 BunshinRL: Splitting Live Agent Workspaces for Memory-Efficient Agentic RL

  • 作者: Yutong Huang; Vikranth Srivatsa; Alex Asch; Yiying Zhang
  • arXiv: 2611.10453
  • 分类: cs.AI, cs.OS
  • 核心创新: Agentic RL rollout 系统，通过内存共享、工具前缀缓存、投机工具执行三项技术利用共享环境状态与重复工具调用。底层 BunshinFork 实现容器级活体工作区 fork（重建进程树、写时复制共享内存、保留文件/通信/GUI 状态）。峰值内存降 43%、总内存降 51%、端到端 rollout 延迟降 23%。

8.4🌟 Represented but Not Used: Value-Policy Dissociation in LLM Agents

  • 作者: Yuzhang Luo; Mohamed Aghzal; Liangming Pan; Ziyu Yao
  • arXiv: 2611.10457
  • 分类: cs.AI
  • 核心创新: 发现 LLM agent 中存在「价值-策略解离」：候选动作的相对价值可从中间隐藏状态线性解码（包括策略选择劣动作的状态），但该表征未被可靠转化为策略选择。提出 Natural Value Transport (NVT) 从隐藏状态变化学习变换，比直接沿价值读出方向干预更一致地影响动作偏好，闭环控制器可改善任务结果。

8.3🌟 Test-Time Scaling for Diffusion Language Models with Frequency-Aware Remasking

  • 作者: Bowen Zuo; Yue Yu; Dongruo Zhou; Yinglun Zhu
  • arXiv: 2611.10486
  • 分类: cs.CL, cs.AI
  • 核心创新: 将 DLM 测试时扩展形式化为推理计算与解码策略的自适应分配。两阶段方法：快速基础采样器解决简单问题，对难题应用频率感知重掩码——追踪每个 token 预测在去噪步骤中的变化频率，优先提交频繁变化的 token 鼓励探索替代推理路径。LLaDA-8B MATH-500 +3.73pp、Dream-7B +7.33pp。

8.3🌟 The Truth Beneath the Tokens: Prompt-Space Recovery of Knowledge Edits in Language Models

  • 作者: Manit Baser; Rachel Yeo Hui Min; Aditya Nawal; Dinil Mon Divakaran
  • arXiv: 2611.10450
  • 分类: cs.CL, cs.AI
  • 核心创新: 证明模型编辑的预编辑知识可仅通过输入空间干预恢复，无需修改权重。Memento 学习可复用恢复信号（连续前缀或离散文本 prompt）引导编辑后模型回到预编辑响应，跨 3 个 LLM 与 5 种编辑技术恢复 80.07% 保留事实。在未编辑 LLM 上平均事实召回 +53.9%，揭示编辑抑制而非消除知识的可恢复性。

8.2🌟 Tactile Sensors Are an Effective Substitute for Wrist Cameras in Contact-Rich Manipulation

  • 作者: Aijia Yang; Arsh Tangri; Sergey Zakharov; Krishna Murthy Jatavallabhula
  • arXiv: 2611.10490
  • 分类: cs.RO
  • 核心创新: 证明手指安装的触觉传感器可有效替代腕部相机。在 visuotactile ACT 策略中集成两个低成本触觉阵列（训练与部署均无腕部图像），在三类接触密集任务上，腕部相机提升 18.3-28.3pp，触觉传感提升 31.7-60.0pp 且在所有三任务上超越仅视觉+腕部相机策略。

8.2🌟 Can General-Purpose Generative AI Supply Training Data for Medical Vision Models?

  • 作者: Jiachuan Peng; Kyle Lam; Jierui Qu; Lin Li
  • arXiv: 2611.10484
  • 分类: cs.CV, cs.AI
  • 核心创新: 回顾性研究评估 Nano Banana 作为合成医学影像来源。仅合成数据训练的模型在肺炎/视网膜脱离/肾结石 AUROC 0.711-0.963 与真实数据模型相当，但校准与净收益不一致。混合训练的颈动脉超声模型产生血管年龄指数分层 633 名外部受试者。强调合成数据价值需用校准、决策曲线分析与临床审查评估，不能仅看区分度。

8.1🌟 LongCapHarness: Capability-Guided Auto-Harnessing for Long-Context Reasoning

  • 作者: Tao Zhang; Yuhang He
  • arXiv: 2611.10463
  • 分类: cs.CL
  • 核心创新: 不依赖数据合成与 LLM 后训练，通过递归自我改进在开发集上修订能力原语实现、能力状态与控制逻辑来 harness 长上下文推理的潜在能力。应用于 Llama3-8B 并迁移至 Qwen2.5-3B，在 HELMET/RULER 上超越数据合成基线，开发成本不到 NExtLong/PolicyLong 训练成本的 50%。

8.0🌟 MuCa-ViT: Disentangling Channel Semantics in Vision Transformers

  • 作者: Daeun Kim; Hyesong Choi; Hyejin Park; Dongbo Min
  • arXiv: 2611.10497
  • 代码: github.com/kimdanni/MuCa-ViT
  • 分类: cs.CV
  • 核心创新: 发现多通道 ViT 中 context token 在高通道冗余下坍缩到少数主导通道。提出 Factorial Token Learning (FTL) 强制 context token 去相关 + Channel Composition-Aware Modulation (CAM) 用精炼 [CLS] 作语义锚生成样本级调制信号。在 JUMP-CP/CHAMMI/So2Sat 三基准超越先前多通道 ViT，改进幅度与通道冗余度正相关。
