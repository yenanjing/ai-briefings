Reconstruction: A Blind Benchmark for Recovering Research Ideas from Pre-Publication Bibliographies
✍️ (cs.AI)🏷️ cs.AI📎 2608.16645

提出「盲法创意恢复」基准——只给模型论文发表前的参考文献，要求还原其真实研究 idea。严格防泄漏协议（时间引用截断、匿名参考 ID、冻结书目）下 7 个前沿模型 Match 率仅 3–15%；跨模型评审 + Swiss 锦标赛多智能体流水线提升到 23–42%（约 2.4×）。为 LLM 能否做真正研究提供可量化评估范式。

HyperSkill: Self-Evolving LLM Agents via Hypergraph-Structured Skill Memory
✍️ (cs.CL)🏷️ cs.CL📎 2608.16114

用超图表示 Agent 经验记忆，节点分「子任务步骤」与「可复用技能」两类，双路径检索 + 结构感知维护（剪枝低效用节点、合并冗余技能）。在 xBench/GAIA/WebWalkerQA 上超越 10 个记忆基线，GAIA +11.51、WebWalkerQA +11.18。

3 ⭐⭐⭐⭐⭐⭐⭐
GRIP: Grounded Reasoning via Information-Restricted Premises
✍️ (cs.AI)🏷️ cs.AI📎 2608.16776

发现 RAG 中「查询主导」失败模式——高容量编码器让 query 淹没证据。GRIP 施加容量不对称：解码器对 query 全维访问，证据经严重随机瓶颈，迫使编码 query 无法提供的残差信息。五个推理基准上超越迭代基线，query-隐变量互信息降低约 30×（14.8→0.47 bits），幻觉降低 73%。

What Does Context Compression Cost an Agent? Interaction Costs Unrevealed
✍️ (cs.AI)🏷️ cs.AI📎 2608.16370

揭示上下文压缩的隐藏代价——完成率不变但被迫重取回被丢弃状态、增加交互成本。受控测量显示检索调用在所有 6 组对比中上升，几乎占全部新增交互；完成率变化均不显著。GPT-5.5 完成率 80%→85%（p=1.0）而检索从 21.0 增至 63.9 次（p=.002）。说明完成率不足以暴露压缩代价。

✍️ (cs.AI)🏷️ cs.AI📎 2608.16349

✍️ (cs.LG)🏷️ cs.LG📎 2608.16710
