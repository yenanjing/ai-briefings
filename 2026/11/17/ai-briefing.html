9🌟 Where Should LLM Agents Adapt at Test Time? In Context, in Weights, or Both

作者: Parsa Mirtaheri, Mohammadreza Armandpour, Keivan Alizadeh, Iman Mirzadeh, Parshin Shojaee, Aryo Lotfi

arXiv: 2611.19700

分类: cs.LG

核心创新: 系统比较 LLM agent 在同一环境中重复工作时两条测试时适应通道——上下文内学习（ICL）与权重更新（RL 微调）——各自的贡献与互补条件。回答了 agent 记忆工程中最基础的「经验该放上下文还是放权重」问题，对 agent 持续学习设计有直接指导意义。

8.8🌟 When AI Agents Should Repair, Replan, or Abandon: A Threshold Theory of Plan Commitment

作者: Gaurav Tewari

arXiv: 2611.19663

分类: cs.AI

核心创新: 针对 agent 执行中发现计划被破坏（动作失败、工具被撤回）的场景，推导出最优策略：以「有效破坏深度」为阈值，在修复（部分重置保留结构）、重规划（完全重置）、放弃之间切换。首次为 plan commitment 给出理论最优解，替代 retry 循环等经验约定。

8.6🌟 Cache or Denoise Less? Residual Reuse in a Flow-Matching World Action Model

作者: Abhinav Gupta, Nissan Pow

arXiv: 2611.19709

分类: cs.RO

核心创新: 在 6B 参数世界动作模型 Fast-WAM 上系统对比跨周期缓存（C³ache）与减少去噪步数两种加速路径，发现仅 2 步非缓存去噪即可在全部 500 个初始状态上保持 10 步成功率（差距 2pp 内），且把单次重规划从 202ms 大幅削减。对 VLA/世界模型推理部署有直接工程价值。

8.5🌟 Data Attribution Should Steer Pretraining

arXiv: 2611.19698

分类: cs.LG

8.4🌟 MathaMAGICal: Validating Trajectory Data Attribution During Capability Acquisition

8.3🌟 Physics-Grounded STL Monitoring from Image Observations

arXiv: 2611.19688

分类: cs.RO

8.1🌟 RIFT: Reward Improvement Field Transfer for Cross-Domain Offline RL

arXiv: 2611.19681

分类: cs.LG
