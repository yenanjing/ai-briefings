📄 论文精选（12 篇）

9.0🌟 G0.7: Scaling Up a Fast World Action Model with Long Context

作者: Tianyuan Yuan, Baijun Ye, Shicheng Cao, Xing Nie 等

arXiv: 2611.31822 · 分类: cs.CV, cs.RO

核心创新: 在 Fast-WAM 基础上把世界动作模型（WAM）扩展为通用型长上下文版本：训练时用视频预测塑造策略表征、部署时跳过未来帧合成，使闭环控制推理速度满足实时要求，同时把观察历史从短窗口扩展到长上下文。将「视频生成器先验 → 机器人策略」路线推向规模化，是 WAM 范式从概念验证走向通用模型的关键一步。

9.0🌟 Self-Upgrading Embodied Agents

作者: Jiajun Fan, Neil He, Qinglong Zheng 等

arXiv: 2611.31117 · 分类: cs.AI

核心创新: 首个在任务间隙「在职升级自身权重」的具身 agent：无需训练基础设施、不依赖更大商业模型，通过 weight-space programming 直接编辑权重从自身经验学习。绕开了反射/记忆/搜索等每步开销且任务切换即失效的方案，把 RSI 从 harness 层推进到权重层。

8.8🌟 fork() for Agents: Agent Kernel for Non-blocking LLM Orchestration

作者: Ankit Chadha, Pratyay Banerjee

arXiv: 2611.31727 · 分类: cs.CL, cs.DC

核心创新: 把分布式系统成熟的子图选择性恢复（Spark/Erlang-OTP 模式）移植到 LLM agent 的内容平面：Agent-Kernel 非阻塞运行时在异常时只重执行失败节点的传递闭包，保留已完成工作。为 agent 运行时提供了操作系统级的容错原语，工程价值高。

8.8 SkillCore: Internalizing Generalizable Skills via Scaffolding-Removed Fine-Tuning

作者: Yi Liu, Changqing Ai, Peijie Dong 等

arXiv: 2611.32246 · 分类: cs.CL

核心创新: 指出运行时技能（skills）只有少数用户会主动加载，提出把可泛化程序性知识通过「去脚手架微调」内化为模型自身能力，将真实 agent 轨迹转化为训练数据。与外挂技能生态（Claude Skills 等）形成互补路线：技能从 prompt 层进入权重层。

8.7 LiveLoRA: Exact KV Cache Migration Across LoRA Updates for LLM Agents

作者: Tianyi Huang, Samuel Xu, Ivy Gu 等

arXiv: 2611.31105 · 分类: cs.AI

核心创新: 解决 agent 会话中适配器热更新必须全量重放历史的痛点：模型-运行时协同设计，冻结低层解码块与 K/V 下投影，使最终块 KV cache 在 LoRA 版本间精确迁移，运行时重建候选 K/V 并验证。对长会话、大规模会话集群的持续学习部署有直接工程价值。

8.7 Steerable by Design: Conditional Pretraining for Robust Control of Language Models

作者: Henry Castillo, Yanchen Liu, Claudio Mayrink Verdun, Dylan Hadfield-Menell

arXiv: 2611.32199 · 分类: cs.LG, cs.AI

核心创新: 主张可控性应在预训练阶段就内建而非靠最后 1% 对齐 token：提出条件化预训练方法与架构，从训练起点就分离指令通道与数据通道，从源头消除越狱与 in-context 对齐漂移。MIT Hadfield-Menell 组参与，安全架构方向信号明确。

8.6 Subliminal Learning Crosses Modalities

作者: Saraswathy Amjith, Kimia Hamidieh, Antonio Torralba, Yoon Kim

arXiv: 2611.31870 · 分类: cs.LG, cs.CL, cs.CV

核心创新: 将 subliminal learning（通过看似无意义的数字序列蒸馏传递偏好）扩展到跨模态：文本偏好经数字序列跨 VLM 传递后，改变扩散模型的图像生成与表征。MIT Torralba/Yoon Kim 参与，对模型蒸馏安全与「数据看似无害实则携带行为」的警示有重要意义。

8.6 SwarmLeak: Does Coordination Improve Privacy Attacks on LLM Agents?

作者: Asma Farajidizaji, Vyas Raina, Vatsal Raina, Ivaxi Sheth

arXiv: 2611.31791 · 分类: cs.CR, cs.CL

核心创新: 首次系统研究多攻击者协同对 LLM agent 群聊的隐私攻击：24 个医疗/法律/金融/软件工程群聊场景，攻击者伪装同事诱导受害 agent 泄露受保护字段，用 GLM 5.2 对 5 个受害模型、7 种对话策略红队测试。量化了「协作是否提升攻击效率」这一此前未知的攻击面问题。

8.5 FATCAT: Fault Injection Attacks Targeting Chip-level Alignment

作者: Peter Horvath, Ilia Shumailov, Zhuoran Liu, Lukasz Chmielewski 等

arXiv: 2611.31129 · 分类: cs.CR

核心创新: 首个能在现代 LLM/VLM 上物理消除拒绝行为的非侵入电磁故障注入攻击：现有对抗评估全部隐含「硬件完整性」假设，FATCAT 打破该假设，在芯片层面破坏对齐机制。将 LLM 安全威胁模型从软件层扩展到物理硬件层，安全社区需重新审视部署环境信任边界。

8.5 ASTERISM: Do Multimodal LLMs Actually Look at All the Images?

作者: Chanseul Cho, Dongwoo Kim, Noori Bae 等

arXiv: 2611.32316 · 分类: cs.CV, cs.AI, cs.CL

核心创新: 审计 19 个公开多图基准共 3.3 万条数据，发现 24.2% 单图即可作答；模型在这些题目上从单图即可恢复 78% 的多图增益——「单图捷径」系统性污染多图评测。为多模态评测方法论提供了大规模祛魅证据。

8.4 Embo-Harness: Towards Understanding Frontier-Model-as-Policy Harness

作者: Xiao-Ming Wu, Kang Liao, Yuexiao Ma 等

arXiv: 2611.31201 · 分类: cs.RO

核心创新: 首个系统研究「前沿模型直接作机器人策略」的 harness 框架：拆解提示、规划、动作执行、工具使用四组件，蒸馏出六条经验性设计原则。为快速膨胀的 frontier-model-as-policy 范式提供了可复用的设计知识。

8.3 Habitats: A Framework for Open-Ended Evolution of Agent Objectives

作者: Nicolas Bolouri, Gaya Mehenni, Daniel Toyama

arXiv: 2611.31160 · 分类: cs.AI

核心创新: 把「agent 应该优化什么」本身变成开放演化问题：维护奖励-策略对种群，每个策略在所有种群奖励下评估形成交叉适应度矩阵，暴露自我博弈盲区，解耦「探索什么目标」与「如何实现」。为开放式学习与奖励设计提供了新框架。
