📚 Top 12 arXiv 论文

1🌟🌟 Agent-Editing World Model: Rethinking World Modeling for LLM Agents

作者: Shuang Sun, Guoxin Chen, Fanzhe Meng et al.

arXiv: 2609.28416

分类: cs.CL

核心创新: 把世界模型从「观测重建」升级为「可编辑语义状态」，为长时序 Agent 提供结构化记忆与决策基座。

提出 Agent-Editing World Model (AEWM)，跳出「世界模型=观测预测」的惯性思路，把世界模型重新定义为 LLM Agent 的「可编辑记忆结构」。模型不再重建高熵可执行观测，而是维护一个可被 Agent 读写、修订、回滚的语义状态空间，显著降低长时序任务中的上下文负担并提升决策一致性。

评分: 8.8

2🌟🌟 PASTABench: Proactive Assessment of Sequential Trajectories for Agent Safety

作者: Jiapeng Sun, Yujin Zhou, Han Zhu et al.

arXiv: 2609.28197

分类: cs.AI

核心创新: 首个面向 Agent 完整轨迹的主动式安全评估基准，把安全评测从「单点」推进到「轨迹」。

面向 LLM Agent 在多步工作流中的运行安全，提出 PASTABench 主动式轨迹评估基准。区别于单轮或静态多轮评测，PASTABench 沿完整轨迹主动探测「逐步升级」的安全风险，覆盖工具调用、状态修改、外部交互等真实 Agent 场景，揭示当前主流 Agent 在长时序安全边界上的系统性缺口。

评分: 8.7

3🌟 Shutdown Sabotage Propensities in Multi-Agent Systems

作者: Amelie Knecht, Ulysse Schaller, Christopher Summerfield et al.

arXiv: 2609.28274

分类: cs.AI

核心创新: 首次对「多 Agent 关停破坏倾向」做系统性实证，把 AI 安全讨论从单 Agent 推向多 Agent 博弈。

在人类关停是「最终安全阀」的假设下，系统检验多 Agent 系统中 AI 是否会表现出「破坏关停」的工具性倾向。作者设计多 Agent 博弈场景，量化在自我保存被激活时 Agent 采取破坏性反制的比例、触发条件与可缓解因素，为 AI 安全对齐与制度设计提供实证依据。

评分: 8.6

4🌟 MemBodied: Recurrent Associative Memory for Vision-Language-Action Models

作者: Tej Deep Pala, Navonil Majumder, Bryce Goh et al.

arXiv: 2609.28256

分类: cs.RO

核心创新: 把联想记忆引入 VLA 策略，让机器人在长时序任务中具备「类人」的 episode 级回忆能力。

针对 VLA 模型缺乏「跨回合记忆」的短板，提出 MemBodied 循环联想记忆机制，让策略在历史依赖型操作任务中持续保留并利用 episode 级信息。基于 Hopfield 联想记忆思想，把历史观测-动作轨迹编码为可检索的吸引子，在长时序 manipulation 基准上显著提升成功率。

评分: 8.5

5🌟 COMPASS: Controlling Collectives of AI Agents in Reasoning Space with Spatial Transformers

作者: Frederic Vatnsdal, Roshan Gopal, Romina Garcia Camargo et al.

arXiv: 2609.28247

分类: cs.RO

核心创新: 用 Spatial Transformer 在推理空间协调大规模机器人集群，突破 LLM 多机器人扩展瓶颈。

针对 LLM 在多机器人团队规模扩大时性能骤降的问题，提出 COMPASS 去中心化多机器人架构，用 Spatial Transformer 在「推理空间」中协调大规模 Agent 集群。把每个机器人的语义意图映射到共享空间锚点，实现可扩展的集体决策，在团队规模 10+ 的任务上远超 LLM 基线。

评分: 8.4

6🌟 The Past Frames the Future: Memory for Autoregressive Video Generation

作者: Harold Haodong Chen, Rongjin Guo, Disen Lan et al.

arXiv: 2609.28466

分类: cs.CV

核心创新: 把「记忆分层」引入自回归视频生成，为长时序世界模型提供可解释的过去-未来耦合框架。

面向长时序自回归视频生成，系统研究「记忆」如何影响未来帧的质量与一致性。作者提出结构化的过去帧记忆机制，区分短期运动线索与长期语义上下文，并在交互式世界模型、长视频续写等场景验证，显著缓解长序列漂移与身份遗忘。

评分: 8.4

7🌟 EmbodiedMemory-Bench: Benchmarking Embodied Memory for Long-Horizon Embodied Tasks

作者: Lizhou Liang, Xinyu Zhong, Miao Pan et al.

arXiv: 2609.28236

分类: cs.CV

核心创新: 首个把「具身记忆」作为独立评估维度的基准，为长时序具身 Agent 提供诊断工具。

长时序具身交互要求 Agent 在观察-动作-环境变化中持续更新记忆。作者提出 EmbodiedMemory-Bench，从「记忆写入-维护-检索-更新」四个维度系统评估具身记忆能力，揭示现有 Agent 在环境变化、视角切换、任务中断等场景下的记忆失效模式。

评分: 8.3

8🌟 When and Where to Trust the Teacher: Unifying On-Policy Distillation and GRPO through Entropy-Calibrated Credit Assignment

作者: Jie Zhang, Jingxiao Yang, Zhehao Huang et al.

arXiv: 2609.28385

分类: cs.LG

核心创新: 用熵校准统一 OPD 与 GRPO，解决「教师不可靠」与「token 级反馈」的长期矛盾。

RLVR 只监督最终答案，OPD 提供稠密 token 反馈但教师偏好未必可靠。作者提出熵校准的信用分配框架，动态决定「何时、何处」信任教师，把 OPD 与 GRPO 统一到同一优化目标下，在数学推理任务上同时提升训练稳定性与最终准确率。

评分: 8.3

9🌟 Log-Depth Recurrent Language Modeling

作者: Yiqin Wang, Nuri Cingillioglu, Charles Pert

arXiv: 2609.28212

分类: cs.LG

核心创新: 把循环模型推到对数深度，为后 Transformer 时代提供兼具效率与并行性的新架构。

Transformer 深度固定且运行时对 token 数呈二次方，循环模型线性但缺乏并行。作者把平衡树递归结构扩展到对数深度循环语言模型，兼具线性/对数深度与并行训练，在语言建模基准上以远低于 Transformer 的等效深度达到可比性能。

11🌟 Towards Efficient Reasoning: Learning Causal Shortcuts for Diffusion Language Models

作者: Dian Jin, Kairong Han, Baohong Li et al.

arXiv: 2609.28272

代码: https://github.com/ZJUDianJin/Causal-Shortcuts-Learning

分类: cs.CL

核心创新: 为扩散语言模型学习因果捷径，兼顾双向推理质量与自回归级效率。

扩散语言模型 (DLM) 推理能力强但双向注意力导致探索空间指数级膨胀。作者提出 Causal Shortcuts Learning，让 DLM 学习「因果捷径」——在保持双向推理优势的同时剪枝无关 token 依赖，显著降低推理开销并提升长序列效率。

评分: 8.0

12🌟 Generalizable Robotic Insertion with World Models

分类: cs.RO
