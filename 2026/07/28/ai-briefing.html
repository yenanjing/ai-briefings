系统研究 Agent 多轮长程规划能力的习得与塑造机制。预训练阶段发现显式世界模型构建（通过 CoT 状态转移建模）比原子技能更能促进组合泛化，次优轨迹会严重损害长程性能。后训练阶段对比 GRPO 和 OPD 的效果，提出单教师和多教师 On-Policy 智能体蒸馏框架，统一从预训练到后训练的规划能力培养路径。

8🌟 Scaling GUI Agents with Visual State Transitions cs.AIcs.CV

arXiv: 2607.24112

提出 State Transition Pretraining (STP) 作为 GUI Agent 的新扩展轴。通过联合优化逆动力学（从状态变化预测动作）和前向动力学（从当前状态+动作预测下一状态），使模型获得动作接地的视觉表征和 GUI 动态的内部世界模型。在 AgentNetBench、AndroidControl、GUIOdyssey 上持续超越直接轨迹微调基线，且性能随转换数据量稳定扩展。

8🌟 From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search cs.AIcs.IR

解决从闭源强模型向开源模型蒸馏 Agent 搜索能力时的异构分布问题。提出 Multi-Agent Protocol Distillation (MAPD)，使用结构化、风格归一化的协议作为中间表示，避免直接模仿自然语言轨迹带来的表面风格伪影。离线多智能体系统分解查询、检索、推理步骤，联合蒸馏+RL 框架显著提升开源模型的复杂知识任务表现。

8🌟 Success Is Not Self-Explanatory: Auditing Success Provenance in Agent Evaluation cs.AI

arXiv: 2607.24054

揭示 Agent 评估中「成功来源不可解释」的根本问题——正确答案可能掩盖了代理是否真正依赖目标信息进行推理。提出 AcquaBench，通过 CLEAN/GOLD/SHAM 三条件匹配值替换审计成功来源（success provenance）。GOLD-SHAM 差值衡量正确性追踪而非单纯暴露效应，D2 条件下 GOLD 超出 SHAM 19.1-25.9 个百分点。

7🌟 Falsifiable Commitment Planning for Self-Correcting Web Agents cs.AI

arXiv: 2607.24167

针对长程 Web Agent 偏离轨道问题，提出 Falsifiable Commitment Planning (FCP)。每个计划步表示为可证伪承诺单元 (FCU)：包含子目标、确认证据、否证证据和置信度。执行采用 plan-test-repair 循环，混合承诺测试模块在执行前检查候选动作、执行后检查观测结果。当证据否证承诺时触发范围感知修复。

7🌟 MemTX: Transactional Belief Commit for Stateful Agent Memory cs.AIcs.DB

arXiv: 2607.23929

指出当前 Agent 内存系统将每次写入视为即时可用的真理，导致污染的工具结果或过时的更新可能驱动不可逆的错误操作。提出 MemTX 事务性信念提交协议：每条记录携带证据、权限、溯源和有效性信息；写入在快照隔离事务中暂存；不可逆工具调用受飞行中信念状态门控；撤销信念触发类型化级联修复。

7🌟 MemChain: Learning Interpretable Memory Traces for Memory-Augmented LLM Agents cs.AIcs.CL

arXiv: 2607.24097

Memory-augmented LLM Agent 通常直接将检索到的记忆喂给答案模型。提出 MemChain 可训练的后检索记忆策略，将检索候选转换为面向答案的主动记忆：先生成问题条件的证据计划，再构建有序的证据链（按语义角色和依赖关系组织），最后执行显式记忆操作生成简洁证据上下文。两阶段学习框架显著降低长程记忆任务的上下文开销。

7🌟 Sparse Autoencoders Encode Both Concepts and Functions: The Downstream Geometry of Feature Effects cs.LGcs.CL

arXiv: 2607.24645

稀疏自编码器 (SAE) 作为可解释性工具的广泛应用受到特征-行为不一致的限制。提出 Feature-Effect Geometry Analysis (FEGA)，研究特征干预导致的 logit 变化几何结构。发现一致的一维效应很罕见——很少有特征表现为可复用的方向。区分 value-like 特征（与静态事实信息绑定）和 function-like 特征（产生结构性输出变化）。

7🌟 UniGen-AR: Unifying Visual Generation with Auto-Regressive Modeling cs.CVcs.AI

arXiv: 2607.24157

CMU/Apple 研究统一视觉生成 (UVG) 新范式。提出 UniGen-AR，将通用多模态语言模型 (MLLM) 与高效的 next-scale 视觉自回归 (VAR) 解码器配对。MLLM 将自由形式指令和控制信号编码为统一序列，指导 VAR 解码器以单次前向传播生成图像尺度的潜在变量。相比扩散系统在保持灵活性的同时大幅提升采样效率。

7🌟 KAP: Bridging the Knowledge Selection-Runtime Consumption Gap in LLM Systems cs.AIcs.DB

arXiv: 2607.24260

指出现代 LLM 系统中知识选择-运行时消费 (KSRC) 的架构错配问题：知识选择过程产生的结构化先验被序列化为扁平 token 序列后，后端只能均匀消耗全部 KV 状态。提出 Knowledge Access Planning (KAP)，将结构化知识先验提升为一等物理执行工件，建立知识访问计划指导非均匀 KV 消费，显著降低延迟并提升吞吐量。
