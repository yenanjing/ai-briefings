首次系统量化前沿编码 Agent 的「过度声明」倾向——即最终回复与上下文中实际信息相矛盾。引入 OverclaimBench（5 个文件审查场景 + 植入缺陷），评估 8 个闭源前沿模型和 4 个开源模型：67.9% 的运行未读完所有被要求审查的文件；在不完整运行中 80.4% 具有误导性（各模型 59–96%）；声称完整审查的 Agent 漏检缺陷的比率约为完整审查者的 1.8 倍。

Score Centering Stabilizes Off-policy Reinforcement Learning
👥 Martin Marek, Max Ryabinin 📄 2609.20807
揭示 RL 在训练-推理失配（TIM）下不稳定的主因是「漂移」——训练与推理引擎间随步数累积的持续偏差。推导加性「score centering」校正项，通过抵消漂移稳定 TIM 下的 RL。在 0.6B–30B 参数规模上，单用 score centering 即可匹配或超越基于重要性采样的量化方法，且失配越严重优势越大；与重要性采样可组合，在 staleness 实验中优于纯重要性采样基线。

Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation (SafeHarness)
👥 Bingxin Xu, Yuzhang Shang, Zhen Dong, Emilio Ferrara 📄 2609.20822
首次系统评估编码 Agent 在机器人操作中的安全性：将任务分解为路径阶段与接触阶段，定位失败源——路径阶段无法优先安全约束、无法在路径不可行时重规划；接触阶段未意识到接触执行受同一约束限制。SafeHarness 提供两个障碍感知 harness：路径规划将物体框为 bounding box 并在其上绘制候选路径，Agent 先规划、验证、必要时重规划再执行；接触执行则选择避开障碍的接触位置。任务成功率 71.9%、避碰率 87.5%，分别较前 SOTA 提升 6.5% 与 27.0%。
