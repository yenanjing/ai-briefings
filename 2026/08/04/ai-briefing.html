TerraNova: A Foundation Model for the Anthropocene

👤 Carlos Rodriguez-Pardo, Massimo Tavoni 📑 cs.LG arXiv:2607.29527

提出 TerraNova 基础模型，统一物理地球系统（512 个网格场）与人类社会指标（512 个国家变量）的几何表示鸿沟。专用编码器+交叉模态 Transformer 融合为共享时空状态，超网络生成 per-query 解码器。在竞争性地学编码器的同时覆盖时间、海洋和不确定性维度，冻结骨干可从稀疏观测重建稠密场并在消费级硬件上分钟级适应新变量。


📂 https://carlosrodriguezpardo.es/projects/TerraNova/
#2 🌟🌟🌟🌟🌟🌟🌟🌟

When Does On-Policy Interaction Help? Representational Tradeoffs in Value-Based Imitation Learning

👤 Luca Viano, Antoine Moulin, Audrey Huang, Volkan Cevher, Philip Amortila, Dylan J. Foster 📑 cs.LG arXiv:2607.29617

Dylan Foster / Volkan Cevher 团队研究模仿学习中专家交互与值函数估计的相互作用。核心发现：专家交互放宽了学习者的表征需求——只需能实现专家值函数的模型，绕过更严格的策略实现要求。提出 OVI 算法在可表示专家值函数时统计有效。证明无交互离线 IL 必须依赖专家策略类复杂度。

#3 🌟🌟🌟🌟🌟🌟🌟

The Parts Are Greater Than the Sum: Automated Task Sequencing for Efficient Training of Multi-Policy LLMs

👤 Jiajia Tang, Sizhe Yuen, Francisco Gomez Medina, Yali Du, Adam Sobey 📑 cs.LG arXiv:2607.29601

Yali Du 团队提出多策略 PEFT 架构：通过任务分组和排序自动组织优化兼容的适配路径，每个路径用独立 QLoRA 实现异质任务解耦优化。TRACE benchmark 上自动多策略框架达 44.78，优于单纯增加适配器容量。表明优化路径组织比增加参数更有效。

#4 🌟🌟🌟🌟🌟🌟🌟

Mixture-of-Translators: Translating KV Caches Across Heterogeneous Large Language Models

👤 Jin-woo Lee, Minkyung Song, Junghyun Oh, Seunghoon Han, Soyoung Park, Gwangseon Jang, Sungsu Lim 📑 cs.CL arXiv:2607.28979

提出 MoT 缓存翻译框架，将源 LLM 的 KV cache 映射到目标 LLM 的缓存空间。使用多个 translator 模块捕获多样映射，引入 Context Correction Loss 对齐重放轨迹。揭示传播翻译偏移和末态偏移两种失败模式。Qwen2.5-7B 规模翻译达 51.0% 封闭 QA 准确率，长上下文保留 96.3% 直接上下文质量。

#5 🌟🌟🌟🌟🌟🌟🌟 🔓 开源

Zero-Mem: Zero-Token Memory Operations for LLM Agents

👤 Yilin Xiao, Zhehan Zhu, Yujing Zhang, Jin Chen, Zijin Hong, Luyao Zhuang, Qinggang Zhang, Shengyuan Chen, Xiaocao Ouyang, Lingfei Ren, Xiao Huang 📑 cs.CL arXiv:2607.29377

提出零 token 记忆操作：除最终 QA 外不调用 LLM。实体-上下文图 + 时间层次双视图组织交互痕迹，确定性校准丢弃冲突证据。长记忆 QA 基准上消除记忆操作的 LLM 调用，记忆操作时间成本降低 57.6%。代码将在审核后开源 github.com/TheMoon0815/Zero-mem。


📂 https://github.com/TheMoon0815/Zero-mem
#6 🌟🌟🌟🌟🌟🌟🌟 🔓 开源

A Frozen Pixel-Space Diffusion Model Can Guide Itself with Its Own Samples

👤 Zixuan Fu, Chong Wang, Lanqing Guo, Kailai Zhou, Jiahao Nie, Bihan Wen 📑 cs.CV arXiv:2607.29122

发现冻结预训练像素扩散模型的中间层可解码为粗糙预测，与最终输出的差异可作为自引导方向。Synthetic Self-Guidance (SSG) 仅需 <1% 全模型训练计算量，无需 CFG 下 FID 降低超 50%，JiT-H/16 从 1.86 降至 1.67，PixelREPA-H/16 从 1.81 降至 1.59。代码开源 github.com/zfu006/SSG。


📂 https://github.com/zfu006/SSG
#7 🌟🌟🌟🌟🌟🌟🌟

TokenSwap: Benchmarking and Reducing the Modality Gap in Multimodal LLMs

👤 Andong Hua, Colton Bishop, Igor Mordatch, Arian Hosseini, Jindong Gu, Aleksandra Faust, Rebecca Roelofs, Yao Qin 📑 cs.CL arXiv:2607.28640

Igor Mordatch / Aleksandra Faust 团队定义模态间隙为语义等价文本输入与多模态输入的性能差异。TokenSwap 方法将文本概念替换为语义对齐图像构建 image-interleaved 基准。42 个 MLLM 上平均 19.6%±3.3% 间隙，推理模型仅 10.1% vs 非推理 25.5%。TokenSwap 训练可有效缩小间隙。

Learning Stateful Predictive Knowledge From Experience

👤 Yan Song, Xidong Feng, Bo Liu, Xinyu Cui, Haotian Fu, Zichen Liu, Mengyue Yang, Cheng Deng, Jian Zhao, Jun Wang 📑 cs.CL arXiv:2607.28638

Jun Wang 团队提出 Stateful Knowledge Learning (SKL)，从轨迹级反思转向维护状态锚定的显式声明性预测评估。通过自蒸馏 (SKL-SD) 和强化学习 (SKL-RL) 训练智能体自主提取状态接地的预测知识。WebShop、ScienceWorld 和 ChessPuzzles 上显著超越当前反思式训练范式。

#9 🌟🌟🌟🌟🌟🌟🌟

ThinkReset: Learnable Intermediate Interface Construction for Bounded-Context Long-Horizon Reasoning

👤 Fei Ding, Yongkang Zhang, Runhao Liu, Yuhao Liao, Zijian Zeng 📑 cs.AI arXiv:2607.28642

指出有界上下文窗口下长程推理的核心瓶颈是可复用中间接口的缺失。识别 outcome-reward-driven 长链 RL 的关键失败模式：窗口将耗尽时鼓励过早猜测。ThinkReset 通过接口回写和重置显式构造可复用中间接口，直接优化重置后继续求解成功率。多个长程推理基准上一致提升。

#10 🌟🌟🌟🌟🌟🌟🌟

MAGA: Multi-Platform Self-Fusion of GUI Agents via Structured Action Distillation

👤 Hang Yan, Zhangxuan GU, Beitong Zhou, Jiaxuan Chen, Runze Li, Yusong Hu, Shuheng Shen, Changhua Meng 📑 cs.AI arXiv:2607.29320

GUI Agent 多平台融合问题。权重合并会因专家分歧破坏可执行动作，OPD 对 action token 和非 action token 同等对待忽略结构。MAGA 根据结构化动作正确性重新分配训练信号，抑制无效蒸馏信号聚焦错误动作。8B 规模超越最强 baseline 2.0%，达到与教师几乎相同的平均性能。

The Grokked Illusion: True Equilibrium Mitigates Catastrophic Forgetting

👤 Xiaotian Zhang, Lai Shun Chan, Yue Shang, Entao Yang, Ge Zhang 📑 cs.LG arXiv:2607.29503

比较 AdamW 训练的 Transformer 与 Wang-Landau 分子动力学采样的高熵模型在灾难性遗忘上的差异。AdamW 模型新数据训练后原任务准确率从 100% 降至 75% 以下，高熵模型保持约 95%。SVD 分析显示高熵模型注意力和 MLP 层有效秩更高，特征表示更丰富可作为抗干扰缓冲。提出 grokked illusion 概念。
