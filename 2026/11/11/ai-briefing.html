9🌟 LaST0.5: A Generalist World Action Model with Interaction-Centric Latent Reasoning

  • 作者：Xuheng Zhang, Yiming Zhang, Jialin Gao, Hao Chen, Jiaming Liu 等
  • arXiv：2611.14048
  • 分类：cs.RO
  • 核心创新：针对现有 World Action Model 直接把全局场景表征迁移到动作生成、忽略交互局部性的问题，提出以「交互为中心」的潜在推理范式，让模型在潜在空间中围绕物体交互区域做定向推理，再落地到动作序列，在通用操作任务上取得更强的泛化与成功率。

9🌟 Can KV Cache Be Reused Across Model Updates? A DeepSeek-V4-Flash Case Study

  • 作者：Zhikun Tao, Fangyong Jin, Junping Zhao
  • arXiv：2611.14051
  • 分类：cs.DC / cs.AI
  • 核心创新：首次系统研究「模型权重更新后 KV cache 能否跨版本复用」这一被忽视的工程问题，在 DeepSeek-V4-Flash 到 Flash-0731 四次版本迭代上做实证，发现 cache 可在权重变化后保留有效任务信息，为推理服务在模型热更新时避免重复计算共享上下文提供依据。

9🌟 Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations via On-Policy Distillation

  • 作者：Lirui Luo, Kelong Mao, Xinwei Yang, Rongqing Li, Luyu Chen
  • arXiv：2611.14009
  • 分类：cs.LG / cs.AI
  • 核心创新：面向长时程编码任务，把「何时写记忆、读什么、何时读」纳入策略本身，用 on-policy distillation 让预训练模型自带的文件操作能力转化为可控的记忆控制行为，摆脱对外部固定 compaction 协议的依赖，显著改善长上下文 agent 的记忆效率。

9🌟 Margin-Guided Token Credit for Reinforcement Learning with Verifiable Rewards (MCPO)

  • 作者：Chi Liu, Xin Chen, Yuchuan Weng, Srinivasan Manoharan
  • arXiv：2611.14015
  • 分类：cs.LG / cs.AI
  • 核心创新：指出 GRPO 把最终奖励均摊给每个 token 的粗粒度问题，提出 Margin-Credit Policy Optimization：用 top-2 概率差 M=p1−p2 度量模型「犹豫程度」，把信用精确分配到决策分歧最大的 token 上，在可验证奖励任务上提升训练效率与最终准确率。

8🌟 Personalized Memory Rubrics: Learning What to Remember per User via Rubric-Guided Credit Assignment

  • 作者：Yupeng Han, Kai Zhang, Shuochen Liu, Ze Liu 等
  • arXiv：2611.14017
  • 分类：cs.AI
  • 核心创新：针对长程个性化 agent 记忆更新只靠终端 QA 准确率给出粗反馈、无法区分中间写入/修改/丢弃操作价值的问题，提出「记忆评分准则」框架，用 rubric 引导的信用分配把用户特定的更新效用显式建模，实现按用户学习「该记什么」。

8🌟 Program-Aided Patchable Skill Evolution

  • 作者：Jiahao Wang, Yuqi Xiong, Qing Yang, Zhipeng Xu, Zhenghao Liu
  • arXiv：2611.14019
  • 分类：cs.CL / cs.AI
  • 核心创新：把 agent skill 从「整段文本重写」升级为「可打补丁的程序化演化」：将技能表示为可组合的程序单元，从执行轨迹中蒸馏可复用经验并以补丁形式精确修改，避免整篇重写带来的副作用，在交互式任务上提升技能适配的稳定性与效率。

8🌟 Where Do Vision-Language Models Get Left and Right? Position-Code Counterfactuals in Qwen2.5-VL, Qwen3-VL and InternVL3

  • 作者：Enhao Cui, Junzhi Yang, Yaoshun Lin, Yuhan Feng, Zijian Chen
  • arXiv：2611.14060
  • 分类：cs.CV / cs.LG
  • 核心创新：通过仅镜像位置编码的反事实干预，系统定位 VLM 的左右方向感来自图像 patch 内容、ViT 位置码还是 LLM token 顺序。在 Qwen2.5-VL-7B、Qwen3-VL-4B、InternVL3-2B 上验证 ViT 宽度位置码是必要且充分的来源，为 VLM 空间推理的可解释性给出清晰归因。

8🌟 Few-Step Streaming Video Generation via Condition Shifting

  • 作者：Deyuan Liu, Jungang Li, Kaiwen Zheng, Kai Jiang, Jintao Chen
  • arXiv：2611.14033
  • 分类：cs.CV / cs.AI
  • 核心创新：针对 Distribution Matching Distillation 需要额外 fake-score 网络、训练显存与计算开销大的问题，提出 condition shifting 直接在生成器内部估计生成分布的速度场，把 APEX 扩展到流式视频生成，实现少步采样下的低成本高质量流式输出。

8🌟 Specify Privacy Yourself: Assessing Inference-Time Personalized Privacy Preservation of LVLMs

  • 作者：Xingqi Wang, Xiaoyuan Yi, Xing Xie, Jia Jia

8🌟 Generalizing Causal Decision-Making: Markov Equivalence, Transportability and Counterfactuals

  • 作者：Min Woo Park, Sanghack Lee
  • arXiv：2611.14066
  • 分类：cs.LG

8🌟 ScaleBrain: A Scale-Consistent Framework for EEG Foundation Models

8🌟 Lipschitz-Controlled Flow Matching for Robust Image Restoration (LipsFlower)

  • 分类：cs.CV
