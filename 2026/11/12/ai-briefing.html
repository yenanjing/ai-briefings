9🌟 A Theory of Policy Optimization in Post-Training: Coverage Collapse and Reference Resets

作者: Audrey Huang, Nan Jiang, Sham M. Kakade, Sadhika Malladi, Akshay Krishnamurthy 等

arXiv: 2611.14467v1

分类: cs.LG, stat.ML

核心创新: 重新审视 LM post-training 中策略优化的理论基础，提出 coverage-preserving 算法类，用 base model 的响应覆盖率（response coverage）刻画样本与梯度步复杂度边界。揭示 coverage collapse 现象并证明 reference reset 可恢复覆盖率，为 RLHF/DPO 等后训练方法提供首个统一理论框架。

8🌟 Is Your Robot's Memory Just a Clock? Temporal Shortcuts in Memory-Augmented VLA Policies

作者: Chubin Zhang, Bo An

arXiv: 2611.14488v1

分类: cs.RO

核心创新: 揭示记忆增强 VLA 策略中的时间捷径问题：均匀时间采样+时间步标记使策略将「等待」误认为「工作」。通过在 RoboMME 计数任务中引入 null event（暂停/手腕抖动）证明策略依赖时间而非实际事件内容，为 VLA 记忆机制设计提出关键警示。

8🌟 AutoScaffold: AI-Guided Scaffolding for Reinforcement Learning of Language Models

arXiv: 2611.14515v1

分类: cs.LG, cs.CL

8🌟 ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows

分类: cs.AI, cs.LG, cs.MA

核心创新: 将 LLM agent 的 SOP 执行蒸馏为可复用 workflow，推理时用代码而非 LLM 选择下一步操作，消除每步调用 LLM 的延迟与成本。从 agent 日志中提取决策逻辑编译为确定性工作流，在业务流程自动化场景中大幅降低推理开销。

8🌟 Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations

作者: Ziang Liu, James J. Kim, Yijia Dai, Jennifer J. Sun

arXiv: 2611.14514v1

分类: cs.AI, cs.CL, cs.LG

核心创新: 针对 LLM agent 科学发现中逐点假设检验的局限（仅测试 h vs ¬h），提出 Contrastive Discovery 框架：用互斥解释的 contrast set 替代单一假设，使 agent 在证据拒绝某解释时能识别证据支持哪个替代解释，实现更有效的开放式科学发现。
