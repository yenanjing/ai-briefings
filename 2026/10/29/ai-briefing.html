8.5🌟 Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis

cs.LG 作者：Andrew Szot, Samira Abnar, Omar Attia, Abbas Kazerouni | arXiv: 2610.37648
核心创新：提出 SynthAPI 管线，沿工具、任务、环境复杂度三轴显式控制合成 tool-use 环境的多样性，首次系统研究数据组成对 LLM 工具使用 agent 训练的 scaling 行为，为 agent 训练数据配方提供可复现的 scaling law 实证。

8.4🌟 GEPA-Curator: Curated Learning for Self Improving Agents

cs.CL 作者：Zack Yu, Nicholas Lee, Minjae Lee, Lakshya Agarwal | arXiv: 2610.37651
核心创新：指出 GEPA 等反思式 prompt 优化器从失败 rollout 学习的根本缺陷——失败可能源于 prompt 弱点、harness 限制、随机执行或噪声 judge，并非都有学习价值。提出策展式学习框架，区分「有信息量的失败」与「噪声失败」，提升自改进 agent 的样本效率。

8.3🌟 ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning

cs.RO 作者：Chaehyun Kim, Chi-Pin Huang, Jisoo Kim, Min-Hung Chen | arXiv: 2610.37666
核心创新：提出从人类视频学习 VLA 的新范式——用世界模型「想象」后续动力学状态作为中间推理步骤（Chain-of-Dynamics），绕过人类视频缺乏动作标注的根本矛盾，在可扩展数据与显式动作接地之间取得平衡。

8.3🌟 EnvSched: Environment-Aware Scheduling for Rollout-Efficient Agent Reinforcement Learning

cs.LG 作者：Sihan Yang, Weichen Bai, Ruichuan An, Yiming Cheng | arXiv: 2610.37609
核心创新：将 agent RL 的效率瓶颈从「策略学习」上移到「环境级数据管理」，联合组织、评估、调度任务实例与生成它们的环境，在有限 rollout 预算下显著提升训练效率，为规模化 agent RL 提供系统级调度方案。

8.2🌟 Heads of Security: Learned Attention Gates Improve Prompt Injection Robustness

cs.LG 作者：Igor Shilov, Xiaoxue Yang, Alexander Panfilov, Evgenii Kortukov | arXiv: 2610.37657
核心创新：提出 HoS 防御——通过少量学习的 per-head attention gate 强制指令-数据分离，让模型在阅读不可信内容时不跟随注入指令。在 Llama-3.3-70B 与 GPT-OSS-20B 上验证有效，是 attention-level 结构性防御而非 prompt-level 软防御。

8.2🌟 Know, then Draw: A New Learning Paradigm for Visual Generation

cs.CV 作者：Yucheng Mao, Chongjian Ge, Zhuowen Tu, Hao Tan | arXiv: 2610.37626
核心创新：提出将视觉生成拆为「知识获取」（自回归预训练）与「高保真渲染」（扩散后训练）两阶段分工范式，系统研究知识获取与渲染的目标、表征与 scaling，为统一视觉生成模型设计提供新思路。

8.0🌟 Can LLMs Uncover Hidden Physical Laws through Free Exploration?

cs.CL 作者：Zhen Yang, Wen Wang, Xander Xu, Ying-Cong Chen | arXiv: 2610.37649
核心创新：提出 LongChang 自动化框架，评估 LLM 在物理规律被改动的世界中能否自主注意到反常现象（如重物下落更慢）并通过实验发现规律——无需被告知调查什么，考察 LLM 的开放式科学发现能力。

8.0🌟 Metacognitive Decoding: Efficient Inference for Diffusion Language Agents

cs.CL 作者：Mingyu Zhao, Shuhang Lin, Ligong Han, Xiaojing Yu | arXiv: 2610.37642
核心创新：为扩散语言模型 agent 提出元认知控制器，根据当前响应需求与 agent-环境交互状态动态决定「在哪里花算力」和「生成多少文本」，实现并行 token 生成下的高效交互。

8.0🌟 VideoLVR: Latent Visual Reasoning over Grounded Video Evidence

cs.CV 作者：Shilong Li, Xingyuan Bu, Hao Shi, Yun Xing | arXiv: 2610.37613
核心创新：针对视频 MLLM 中 CoT 推理导致的「视觉遗忘」，提出在潜在空间中对锚定视频证据进行视觉推理，使模型在推理链中可持续回访相关视觉内容，而非仅依赖语言 trace。

8.0🌟 Honeycomb-Surfels: Compact Hexagonal Primitives for Efficient Scene Rendering and Reconstruction

cs.CV 作者：Prakhar Kaushik, Soumava Paul, Alan Yuille | arXiv: 2610.37668
核心创新：提出 Hexels——平面六边形表面元素 + 一阶空间颜色场，作为 radiance field 与 splatting 之外的新 3D 场景表征，利用局部平面区域平滑变化的假设显著降低内存与计算开销，适配资源受限场景。

7.8🌟 Attention as Lattice Gauge Theory: Relations Interact Only Through Wilson Loops

cs.LG 作者：Aakash Sarkar, Ananya Mukherjee, Motoshige Sato | arXiv: 2610.37656
核心创新：将 attention 中的关系组合映射为格点规范理论——若每个实体坐标系可独立旋转（per-entity frame freedom），则关系仅通过 Wilson loop 闭合相互作用，为关系推理的组合性与顺序性提供物理学启发的形式化解释。

7.8🌟 Can Discrete Tokens Serve as Semantically Lossless Representations of Visual Signals?

cs.CV 作者：Jialv Zou, Xiaotong Li, Zhengrong Yue, Xu Huang | arXiv: 2610.37662 | GitHub: hustvl/FVQ
核心创新：挑战「量化误差必然导致语义损失」的共识，证明离散视觉 token 可以作为语义无损表征，为多模态建模中「共享 next-token prediction」的离散接口提供理论支撑与实证。
