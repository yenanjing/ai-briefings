1 8.3🌟 cs.AI
CUA-Universe: A Scalable and Dynamic Environment for Hybrid GUI+CLI Agents
👤 Haoting Shi, Wenhao Wang, Weicheng Fang 等 9 人📄 arXiv:2609.05374

把真实桌面软件自动改造成 GUI+CLI 混合操作环境：App-Forge 将应用封装为可复现虚拟机并自动发现/包装/生成命令行接口（已扩展到 16 个应用），Task-Weave 从可复用操作合成可控难度的混合任务，Path-Steer 引导 rollout 走高效混合路径并采集已验证轨迹用于后训练。在此数据上训练后，9B 模型在 CUA-Verse 上成功率与效率同步提升，行为从低效的纯 GUI 操作和脆弱的 CLI 脚本转向 GUI+CLI 协同编排。

2 8.1🌟 cs.AI 开源
TruthInsightBench: An Evidence-Grounded Benchmark for Automated Evaluation of Open-Ended Scientific Discovery Agents
👤 Zhibo Yang, Chen Zhang, Yuewei Zhang, Hao Wang📄 arXiv:2609.05079💻 github.com/TruthInsight-stack/TruthInsightBench

首个面向「发现」而非「复现」的科学发现 Agent 基准：40 个盲任务取自 10 个学科的 40 篇同行评议研究，只给出中立的科学目标和冻结数据，源结论、期望数值与分析路径全部隐藏，由 Agent 自行判断数据支持什么主张。固定 LLM 评判沿 6 个维度、29 项证据锚定条目为 Agent 自己的主张打「证据成熟度」分，聚合过程确定性自动完成、无需逐例人工评分，可随 Agent 演进而反复自动重跑。

3 7.8🌟 cs.AI
Molecular Déjà Vu: Digit-Level Retrieval of Published Values in Frontier Language Models
👤 Matthias Busch, Marius Tacke, Sviatlana V. Lamaka, Mikhail L. Zheludkevich 等📄 arXiv:2609.05381

审计 22 个前沿模型在 12 个分子性质回归基准上的「逐位复述」式记忆：5 个数据集中超过 50% 的模型出现逐字检索，其余数据集仅零星出现；在两档推理强度下对比，高推理档被判定为复述的次数比最低档多 89%；即便用变换后的 SMILES 干扰，最强模型仍能识别部分组合。结论是分子基准上的高分无法区分「预测」与「背答案」。

4 7.7🌟 cs.RO
Same Trajectory, Contradictory Rewards (ROBORMBENCH): Paraphrase Fragility in Vision Language Reward Models
👤 Wonje Jeung, Sangyeon Yoon, Hyesoo Hong 等 9 人📄 arXiv:2609.05401

揭示 VLM 充当机器人奖励函数时的「释义脆弱性」：仅改写指令措辞就能显著改变预测进度分数，甚至把同一条机器人轨迹在成功与失败之间翻转。为此构建含 2,390 条真实机器人轨迹、真值进度标签与 21,673 条校验过释义（词汇/句法/动作目标三类改写）的基准；跨闭源与开源 VLM 测试显示该不稳定性普遍且严重，改写差异越大越明显，模型规模与显式推理都不可靠缓解，而用轨迹接地监督专门训练的奖励模型稳定得多。

5 7.6🌟 cs.AI
Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability
👤 Ankit Goyal, Jaideep Ray📄 arXiv:2609.05339

受控研究「模型升级后 Agent 记忆还剩下多少」：对比原文长上下文（LC-RAW）、RAG 分块、模型压缩笔记（NOTES）、固定 schema 知识图谱（KG-fixed）四种记忆形态，使用 48 条带随机答案码的合成历史、精确打分和两个 10B 以下开源模型。结果显示固定 schema 结构迁移稳定（更换写模型后 KG-fixed 准确率仅变化 +0.0004±0.0020），而压缩笔记与写模型强耦合，准确率随具体模型组合不对称漂移 +9.91 或 -13.28 个百分点。

6 7.5🌟 cs.AI
RISE: Recursive Improvement via Self-Extrapolating Policy Distillation
👤 Yang Li, Semih Yavuz, Shafiq Joty📄 arXiv:2609.05295

把 RLVR 训练轨迹本身变成教师：通过外推当前 checkpoint 与尾部 anchor 之间的位移（参数空间或输出 logit 空间），把稀疏的结果奖励转成稠密的 token 级监督目标，无需任何外部模型或特权条件。RISE 把 RLVR 与 on-policy 蒸馏组成互补闭环——结果奖励把外推锚定到正确推理，外推教师再细化 token 级决策；教师每轮随学生一起刷新，使蒸馏成为递归自我提升机制而非一次性压缩。在数学推理、多域 STEM、代码生成与多轮 Agent 任务上全面超过纯 RLVR 和自蒸馏。

7 7.4🌟 cs.AI
Multi-Step Tool-Calling over Korean Open Public APIs: A Benchmark and a Data-Synthesis Recipe
👤 Dain Kim, Eungi Cho, Kyumin Kim, Shinyeong Noh, Kyuseong Lim📄 arXiv:2609.05395

面向数据主权场景的多步工具调用基准 KOPA-Bench（145 个真实任务），并提出 EDGE——一个由真实执行驱动的动态图数据合成框架：只保留实际调用 live API 后成功连通的「输出→输入」链路，再遍历这些已验证链路合成可执行的多步轨迹。用 GRPO 在合成数据上微调后，9B 模型几乎追平同族未微调的 27B 模型，在 KOPA-Bench 与 BFCL 上均大幅提升。

8 7.3🌟 cs.AI
GUT: Quantifying and Optimizing the Reasoning Uncertainty of LLMs via Graph Complexity
👤 Shuang Liang, Xin-Yu Hu, Xiang-Jun Ou, Shao-Qun Zhang📄 arXiv:2609.05284

用有向无环图刻画 LLM 推理链的所有潜在分支，把推理空间复杂度近似为图复杂度来量化「推理不确定性」（GUT-Q）；再把负的不确定性作为强化学习奖励函数来优化（GUT-O），从而压缩不合理、荒谬的推理分支。在 4 个 LLM、5 个数据集上验证有效性。

9 7.2🌟 cs.AI
Testing Interchangeability in LLM Agent Teams
👤 Jianxin Gao, Tianyi Yu, Linna Deng, Runze Li, Zining Wang📄 arXiv:2609.05279

实测多 Agent 团队「角色可替换」这一生产假设：每个设置独立组建 8 支队伍、每个 Agent 保留私有笔记跨 10 轮成型，再在队伍间调换角色匹配的 Agent。结果显示调换对任务分数影响不大，但单位进度的沟通开销上升 16–63%；在 Hanabi 中被调换的 Agent 比新手更贵（与旧搭档习得的惯例产生干扰）。Agent 在任务结果上比在协调效率上更具「可替代性」，成型历史越长调换代价越大。

10 7.2🌟 cs.AI
Don't Drop Dropout: Optimizing Layer Sparsity for Efficient LLM Training and Inference
👤 Mostafa Elhoushi, Alex Pretko, Nolan Dey 等 9 人📄 arXiv:2609.05275

系统论证 layer dropout（随机深度）应重回 SOTA LLM 预训练配方：在最优层分布、时间调度与优化器超参下，相同训练 FLOPs 下 layer dropout 带来更低 loss，相同步数下可省最多 25% 训练 FLOPs 而 loss 持平或更低；还能解锁早退、中间层跳过、自投机解码等后训练优化，带来最多 1.5× 推理加速且精度几乎无损。结论基于 2400+ 实验、271M–8.2B 参数规模，全部在 Cerebras CS-3 上跑。

11 7.1🌟 cs.RO 开源
RoboSPA: Can VLA Models Go Beyond Simple Scenes and Short-Horizon Tasks?
👤 Zhenxuan Fan, Bo Zhang, Yutong Lin 等 12 人📄 arXiv:2609.05324💻 github.com/fanzhenxuan/RoboSPA

大规模机器人操作诊断基准，聚焦「细粒度空间推理」与「长程程序规划」两个维度，覆盖 10 个任务类别、56 个基础任务，每个任务 5 个难度档共 280 个变体，跨多种本体与场景采集 527K 条轨迹。除二元成功率外引入诊断指标；实验显示当前 VLA 在复杂空间关系、精确低层执行与记忆密集规划上仍吃力。

12 7.0🌟 cs.LG
PRICE: A Systematic Study of LLM Adaptation Choices for Bitcoin Price Forecasting
👤 Maryam Fakhari, Mehran Safayani📄 arXiv:2609.05235

系统研究 LLM 适配短周期比特币价格预测的各项选择：基于 4-bit 量化的 LLaMA-3 8B，组合 LoRA 参数高效微调、递归多步推理、整数取整数值表示、CTF 提示与零温精确解码。消融显示每项组件都有贡献（CTF 提示优于 CoT/iCoT/少样本，零温解码提升递归预测稳定性）；对比 8 个 transformer 与时序基础模型，PRICE 在验证集与测试集上均取得最低预测误差。
