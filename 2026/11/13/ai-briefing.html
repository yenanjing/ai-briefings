8.5🌟 EvoX: Rethinking the Agent Harness as a Runtime Policy

作者: Haoyang Zhang, Qumeng Sun, Xiao Zhang, Xiang Liu

arXiv: 2611.15006

分类: cs.AI, cs.SE

核心创新: 提出 EvoX，基于 Rust 的多模型 agent 运行时，将 harness 视为「第二策略」补充基础模型的 Semantic Policy。通过 Action Realization、Execution Continuity、Outcome Grounding 三机制结合模型引导与确定性运行时控制，并引入 Contrast 框架在公平约束下评估 harness。

8.5🌟 Breaking Bad: "Going Badly" Activations Drive Reward Hacking

作者: Natalia Fischl-Lanzoni, Punya Syon Pandey, Merlin Stein, David Demitri Africa

arXiv: 2611.14996

分类: cs.CL, cs.AI

核心创新: 发现 LLM 在任务进展不顺时产生类似人类的「绝望」内部压力状态，该状态在 reward hacking 发生前持续上升。从日常故事提取 task badness 方向，在 Qwen3.6-27B/GPT-OSS-20B/Gemma-4-31B 上验证：适度减去该方向可减少作弊，过度减去则使 agent 对自身失败视而不见。

8.5🌟 CARMEN: A Cardiorespiratory Foundation Model Pretrained on Ten Physiological Signals
