⭐ 9.0 Say the Same, Act Differently: Diagnosing and Steering Text-Action Divergence in Reasoning VLAs

作者: Zihao Feng, Qingzhao Zhang, Chunyu Xia, Bo Yu, Z. Morley Mao, Ramesh Govindan
arXiv: 2611.04166 · 分类: cs.LG
首次揭示推理 VLA 存在「文本-动作分歧」新失效模式——视觉扰动可在保持 rationale 逐字不变的前提下改变物理动作。TNAS 诊断证明最具动作敏感性的方向与文本损失梯度近似正交（1.87%/5.28% 范数重叠），沿该方向干预对动作的偏移是文本梯度扰动的 4.64×–47.8×。对 VLA 安全监控具有根本性意义。

⭐ 8.9 Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training

作者: Kangning Zhang, Wenxiang Jiao, Bowen Fang, Shuai Shao, Jiachen Zhu, Rong Shan
arXiv: 2611.04277 · 分类: cs.AI
提出 harness 进化三定律（Locality/Complementarity/Nonstationarity），拒绝寻找普适最优 harness。Directional Harness Evolution 沿不同修复方向训练专用 sibling harness 形成固定池；Complementary Harness Rescue Training 仅在 base harness 全部初始尝试失败时调用池，用辅助轨迹替换失败组做 RL，将 sibling 能力蒸馏回单一策略。

⭐ 8.7 DoGNAVY-Exploit: Harnessing Parallel Open-Weight Agents for Stage-Aware Vulnerability Exploitation

作者: Yuxuan Wang, Dadi Guo, Weijie Guo, Zikai Xu, Chen Lu, Yizhe Zhuang
arXiv: 2611.04196 · 分类: cs.AI
针对开源权重模型在长链漏洞利用中「无法跨阶段维持进度、无法在正确阶段应用安全知识」的问题，提出阶段感知分解 + 渐进式专家知识披露 + 分层编排并行探索的多 agent harness。用可配置里程碑把长程利用重铸为短、可验证的能力跃迁。

⭐ 8.6 DualWorldBench: Can Agents Plan Deliveries across Symbolic and Grounded Worlds?

作者: Yang Chen, Bin Wen, Danyang Peng, Hong-Jie You, Zi-Qiao Shang, Lan-Zhe Guo
arXiv: 2611.04228 · 分类: cs.AI
统一评估 agent 在「符号-时间」与「落地-拓扑」两个复杂度轴上的规划能力。围绕共享取送接口构建 TextWorld（符号规划）、SimWorld（落地路径规划）、DualWorld-VQA（诊断套件）三组件，系统揭示当前多模态 agent 在时间/物理/多模态约束下多目标规划的脆弱性。

⭐ 8.5 Where Did the Update Go? Certifying Declared Change Envelopes for Model Updates

作者: Muhammad Usama, Muhammad Saad Qadir
arXiv: 2611.04192 · 代码: Usama1002/declared-change-envelopes · 分类: cs.LG
形式化「声明变更包络」问题——区别于「变化多少」的界限，「变化在哪里」是不同统计问题。开发者训练前承诺输入区域，区域外任何决策变化计为泄漏；可用 anytime-valid 检验从无标注流量认证，单次认证可组合为生命周期漂移上界。覆盖 LoRA/全参微调/偏好优化/RL。

⭐ 8.4 Tokenizer Myths and Where To Find Them

作者: Rylan Schaeffer, Sanmi Koyejo
arXiv: 2611.04215 · 分类: cs.CL
系统挑战 tokenization 研究三大迷思：BPB 对 tokenizer/词表大小不敏感、低 BPB 意味着更好模型、不同「tokenizer 无关」指标给出一致结果。用未训练模型证明 BPB 强烈偏好某些 tokenizer/词表大小，与下游性能仅弱相关，对评估方法论有直接修正价值。

⭐ 8.3 SPOD: Recovering Suppressed Temporal Evidence in Video-LLMs via Single-Pass Orthogonal Decomposition

作者: Yangguang Lin, Quan Fang, Xiaoyan Liu, Zefan Xu
arXiv: 2611.04728 · 代码: VioAgnes/SPOD · 分类: cs.CV
发现 Video-LLM 时间证据已编码在隐藏表示中但未被标准推理充分利用。提出免训练单次前向框架，通过 Frame Distinctiveness Analysis + 正交分解恢复被抑制的时间证据，无需重训或多 pass 推理即可缓解时间幻觉。

⭐ 8.2 AceAction-5M: Hierarchical Goals for Generalist Action Learning Across 3D Game Worlds

⭐ 8.1 When Debate Amplifies Risk: Social-Bias Vulnerabilities in Multi-Agent Safety Deliberation

作者: Qinghua Mao, Xi Lin, Yuxin Qi, Zihao Xu, Jinze Gu, Yuliang Chen
arXiv: 2611.04289 · 分类: cs.CR
首次系统揭示多 agent 辩论（MAD）中「社会结构反而放大 Web 潜在安全风险」这一反直觉现象。提出 SafeConflict-Bias 受控反事实诊断协议，覆盖六类 Web 风险，在严格保持查询与证据不变的前提下隔离从众压力、权威线索、信心不对称三类社会偏差。

⭐ 8.0 Reliability Stress Testing of RAG Retrieval under Query-Relevant Corpus Poisoning

作者: Janet Sung, Kainan Zhou, Gangzhen Qian, Hang Xiao, Lu Yi
arXiv: 2611.04264 · 分类: cs.AI
系统压力测试 RAG 检索准入环节。在 BEIR 623 查询上，每查询 5 篇目标毒化文档使经典检索器 nDCG@10 下降 40.2–61.5%；识别「全查询锚定」是 BM25 退化主因，附加文本则改变 LSA 与 Hybrid 排名。BGE-small 验证显示查询锚定仍是主导攻击向量。

⭐ 8.0 Agentic Path Maps: Exposing an Agent's Traversal Through the Garden of Forking Paths

作者: Madeleine Grunde-McLaughlin, Hafsah Usman, Daniel Mitroshkov, Emily Reif 等
arXiv: 2611.04183 · 分类: cs.HC
提出面向 underspecified 任务执行后的「替代路径」通信设计空间，并测量「显示替代路径数量」对用户理解的影响。48 人用户研究显示：用户很少主动考虑替代路径，但可视化后 AI 过度依赖降低，为 agent 透明性与用户校准提供 HCI 视角。

⭐ 7.9 LoopKV: Loop-Aware KV Cache Compression for Serving Looped Transformers

作者: Tianle Zhou, Yang Zhang, Tianyu Wu, Zhuohan Wang, William Nixon, Juncheng Yang
arXiv: 2611.04137 · 分类: cs.LG
针对 Ouro 等循环 Transformer 每个 loop 独立 KV cache 导致显存限制 batch size 的问题，发现量化敏感性与共享损伤在 (loop, layer) 单元上差异显著。LoopKV 用一次性离线 profile 为每个单元选择 4-bit/2-bit/复用末轮 KV，在预算下最小化读取。
