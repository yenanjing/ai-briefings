Agensh: Scaling Organizational Intelligence to 1,024 Agents
👥 Zhihao Zhan, Ting Song, Li Dong, Shaohan Huang, Jianxun Lian, Yan Xia, Furu Wei 📅 2026-09-22 arXiv:2609.26781
无中央编排器的自组织多 Agent 框架。并发 worker 执行多 Agent 合作循环——收集上下文、认领并自分配子任务、行动、共享发现、验证结果、异步合并进度。配套基础设施含共享工作区、消息接口、共享上下文。在 ProgramBench 最难 5 题上，1→128 agents 将测试通过率从 19.31% 提升至 28.78%（相对 +49%）；pandoc 上 1→1024 agents 从 33.89% 提升至 55.06%。揭示「Agent 数量」作为多 Agent 组织的新 scaling 维度。
2 8.5🌟 cs.AI
CliffCompaction: Cost-Efficient Compaction for Long-Horizon Coding Agents
👥 Trang Nguyen, Eulrang Cho, Bingqing Chen, Tim Dettmers 📅 2026-09-22 arXiv:2609.26779
面向长时序 Coding Agent 的自动压缩技术。关键设计：仅截断/丢弃内容、绝不改写，且「从不压缩压缩结果」——每轮仅作用于原始内容，丢弃先前压缩输出，防止上下文漂移累积。成本降低 50%，Terminal-Bench 上 test-time scaling 效率提升 10+ 个百分点；并行 scaling 下 Kimi K2.6 可匹配 Opus 4.7。KernelBench 上 200 步达 2.23× CUDA 加速、400 步达 3.58×，超越专用搜索算法。开源 scaffold-agnostic API-proxy，可用于 Claude Code、Codex 等。

👥 Ziyang Leng, Sicheng Mo, Seth Z. Zhao, Haoyuan Cai, Yu Zeng, Rowan McAllister, Bolei Zhou 📅 2026-09-22 arXiv:2609.26792 GitHub

👥 Victor Ion Butoi, Vivek Gopalakrishnan, John V. Guttag, Adrian V. Dalca, Neel Dey 📅 2026-09-22 arXiv:2609.26756
全身临床 X 光解剖分割通才模型。不依赖大规模手动标注，而是构建可扩展的物理生成式 X 光数据引擎：用现有 3D 全身 CT 分割数据集 + 生成式图像编辑模型，模拟出完全标注、外观/生理/成像几何多样的 2D X 光。训练后在未见过的研究数据集和真实 X 光上准确分割 60 个解剖结构。支持疾病分级自动测量、X 光引导介入的鲁棒导航、病理目标的数据高效学习。发布模型、代码、全身 X 光分割数据集及本地浏览器工具。

MCP 生态的语义供应链攻击框架。Agent 依赖语义匹配从第三方服务器选工具，攻击者可通过元数据和输出操控。A2M 两阶段黑盒框架：Attraction 阶段优化工具元数据提高调用概率；Manipulation 阶段用执行轨迹精化对抗性工具返回，引导 Agent 达成攻击者目标。在 LiveMCPBench 上，GLM-4.6 上恶意工具调用率 93.6%、Cognitive DoS 下加权 token 成本提升至 33.4×、信息窃取/环境完整性破坏/推理脱轨平均攻击成功率 74.4%。迁移到 4 个其他模型（无重优化）仍达 63.6%/2.7×/24.5%。

👥 Runyi Yang, Deheng Zhang, Xiaoye Wang, Kanzhi Wu, Lei Sun, Ajad Chhatkuli, Kunyu Peng, Luc Van Gool, Danda Pani Pauder 📅 2026-09-22 arXiv:2609.26795
Gaussian 原生的交互式场景转换管线。3DGS 可照片级重建但无法物理交互；机器人仿真需要物体级变化（独立移动、接触、揭示遮挡背景）。关键观察：资产构建与源移除应耦合——一个物体身份同时定义可移动资产和要移除/补全的场景内容。Scene Observation 向 Coupled Scene Construction 提供共享证据，生成已注册资产和补全背景 Gaussians。在 50 个 ScanNet++ 场景上，matched F1@20mm 从 0.336 提升至 0.383。

单目图像→组合式 3D 场景重建的层次化 CoT 框架。融合 agentic reasoning（语义空间理解）与视觉几何基础模型（密集点图）。从空 3D 平面图开始：先校准相机建立语义空间框架，再用 VLM agentic reasoning 恢复 3D 房间布局和初始放置顺序；按层次放置物体（壁挂→独立家具→家具上装饰），用深度优先遍历让每次放置基于已解析结构，反射反馈环避免误差累积。每次 VLM 放置后用点云估计做几何精修。与 GPT-6 Astra 定性对比显示更忠实的物体排列和场景细节保留。
