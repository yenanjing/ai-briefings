SeeQ: Training Generalist Value Functions for Long-Horizon Robotic Manipulation
👥 Saksham Singh, Zheyuan Hu, Max Sobol Mark, Jeffrey Yu, Zackory Erickson, Aviral Kumar 📄 2609.22085
针对长时序、多阶段、需反复尝试的机器人操作任务，提出 SeeQ（Subtask-elicited Q-functions）：不为整段任务学 Q 值，而是为「当前活跃子任务」学 Q 值，从而缩短价值预测视界、使 TD 目标可有效学习。Q 函数架构在估计价值前先自回归预测自然语言形式的活跃子任务，免除测试时的人工标注或模块化子任务预测器。在两个双臂机器人平台的四项真实操作任务上，SeeQ 显著提升 best-of-N 策略成功率。

An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity (MDL)
👥 Yiming Zhang, Jinghong Zhang, Haoran Zhao, Yiren Ma, Chunlei Zhao 📄 2609.22043
现有 LLM 记忆系统聚焦于「高效检索」，却忽视了「检索到的记忆是否应被信任」。受前额叶皮层记忆信号机制启发，提出 Memory Decision Layer（MDL）：一个位于检索与生成之间、零参数的记忆决策控制器。核心是三信号互补编码器，通过 QR 正交子空间投影将相关性、可靠性、任务风险与元工作记忆信号融合为可解释的决策表示，显式解耦 confidence 与 consistency，并引入 risk inversion 与显式 abstention。在主流 LLM 与多个开源数据集上，冲突记忆下的幻觉率平均降低约 56.04%，高风险场景接近零幻觉。

λ-Controlled GRPO: Turning Flow-Matching Ratio Instability into a Budgeted Resource
👥 Yufeng Wang, Parivesh Priye, Meeshawn Marathe, Ramit Pahwa 📄 2609.22041
Flow-GRPO 将 RL 对齐扩展到 flow-matching 图像生成模型，但多步去噪过程中重要性比会系统性漂移、分散、被裁剪，导致可用样本越来越少。本文证明这些现象并非独立失效模式，而是源自单一 per-step 量——path variance，该量由采样器的高斯转移核精确决定，可在训练中廉价估计。λ-Controlled GRPO 据此校准重要性比行为、按预测代价分配各去噪步的梯度投入，两个尺度均由标准策略选择固定而非新增自由超参。

12 7.8 cs.HC
Value-Sensitive Delegation in Everyday AI Agent Use: Evidence from OpenClaw
👥 Renkai Ma, Ruyuan Wan, Xuan Lu, Fan Yang, Chen Chen, Lingyao Li 📄 2609.22067
用户越来越多地将工作委派给自主 AI 智能体，但评估通常只衡量任务完成度而非用户所重视的价值。作者用 Value Sensitive Design 方法、借助 LLM 分析了 73,093 篇 Reddit 上关于 OpenClaw 使用的第一人称帖子，提炼出 21 项价值、六大价值组（自主/可靠/可负担运行、有界触达、可审查性、公平获取）。价值并非落在智能体输出上，而是聚集在用户围绕一次运行设定的「运行条件」上——在「智能体交付了什么」的描述中价值多半得到满足，而在「用户监督它」的描述中价值多半未被满足，作者将此模式概念化为 value-sensitive delegation。
