2 🌟 Vidu S2：实时交互、可编辑、空间视频生成
👥 Jintao Zhang, Kai Jiang, Jintao Chen, Xu Wang 等 📂 cs.CV, cs.LG arXiv:2609.11638

包含 Vidu S2-Avatar（实时交互数字角色）和 Vidu S2-Editing（实时视频编辑），支持实时 720p 视频生成、动态参考生成、可编辑视频内容及空间视频生成探索。相比 Vidu S1 在实时性和交互性上大幅提升。

3 🌟 MindTopo：基础模型能在拓扑空间中推理吗？
👥 Yunfei Ge, Anbang Liu, Qineng Wang, Johnalbert Garnica 等 📂 cs.AI, cs.CL, cs.CV arXiv:2609.11900

引入 MindTopo 基准，评估基础模型在拓扑空间中的推理能力。认知科学将拓扑关系视为空间理解的基础，但现有评估多聚焦度量或视角依赖关系。该工作填补了拓扑推理评估的空白。

4 🌟 Caption-once, Frames-on-Demand：预算感知的长视频理解 Agent
👥 Weitong Cai, Hang Zhang, Yukai Huang, Yiqiao Xie 等 📂 cs.CV, cs.HC arXiv:2609.11899

发现视觉-文本二元性：语言记忆比密集帧更好地携带长程时间结构，而像素对属性级细节更具决定性。提出视觉需求路由机制，在边缘设备上实现预算感知的长视频理解 Agent。

5 🌟 World in World：用世界模型探索世界
👥 Chenxi Song, Yanming Yang, Chi Zhang 等 📂 cs.CV arXiv:2609.11548

自回归视频世界模型，支持交互式长程探索。解决从新视角探索源视频时的同步性、视角内容放置、新暴露区域合理补全及重访时外观恢复等挑战。

6 🌟 开源 OmniKVQuant：全模态 LLM 的 KV Cache 量化
👥 Suho Yoo, Hyunjong Ok, Jongmin Choi, Jihoo Jung 等 📂 cs.CV arXiv:2609.11582 GitHub

首个针对全模态大语言模型（Omni-LLM）的 KV Cache 量化研究。分析 TurboQuant 在多模态缓存上的行为，识别两个关键问题并提出解决方案，降低音频+视频+文本同时输入时的内存开销。

7 🌟 OmniHallu：多模态大语言模型的统一幻觉检测
👥 Jianjiang Yang, Peihang Li, Shanqing Xu, Mengchen Qian 等 📂 cs.CL, cs.CV arXiv:2609.11244

统一幻觉检测框架，覆盖跨模态理解与生成。现有研究多局限于单一模态或任务类型，OmniHallu 实现了多模态大语言模型的通用幻觉检测。

8 🌟 Show-Harness：让 VLM Agent 直接「玩」机器人
👥 Yanzhe Chen, Zechen Bai, Zhijun Cao, Wenzheng Zeng 等 📂 cs.RO arXiv:2609.10522

具身 Harness 框架，通过紧凑的语义接口将意图链接到动作，使视觉语言模型（VLM）能够操控机器人。暴露离散语义动作单元，实现从智能到机器人控制的转化。

9 🌟 HaWMPO：幻觉感知世界模型策略优化
👥 Zengjue Chen, Peidong Liu, Jiawei Li, Qi Wang 等 📂 cs.RO arXiv:2609.09941

幻觉感知世界模型策略优化，解决通用机器人策略在复杂长程场景中的成功率问题。通过世界模型进行在线强化学习，避免昂贵的物理交互训练。

10 🌟 Belief-State Engine：部分可观测下的 LLM 规划增强
👥 Arnab Chattopadhayay, Debdipta Halder 📂 cs.RO arXiv:2609.10036

信念状态引擎，增强 LLM 在部分可观测环境下的规划能力。解决 LLM Agent 在环境部分可观测时的特征性失败：模糊反馈导致过早承诺、单次信息观测将不确定性坍缩到错误假设、策略漂移等问题。

11 🌟 SurgicalRoomAgent：智能手术室语音交互多 Agent 系统
👥 Tianxiang Zhou 📂 cs.AI, cs.CL, cs.HC arXiv:2609.11231

基于 LLM 的语音交互多 Agent 系统，用于智能手术室。通过分层架构实现自然语言理解、设备控制、术中记录和手术报告生成，包含语音交互流水线（唤醒、ASR、轮次检测、Agent 推理、TTS）。

12 🌟 REVA：上下文高效 RAG 服务的可复用证据视图聚合
👥 Tuan Nguyen, Qiran Hu, Banruo Liu, Khoa D. Doan 等 📂 cs.LG, cs.CL, cs.IR arXiv:2609.11209

可复用证据视图聚合，降低 RAG 服务的上下文成本。现有压缩器多为每个查询独立操作、依赖辅助模型或重写，REVA 通过可复用视图聚合减少延迟、KV 缓存内存和 token 成本。
